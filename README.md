# Portfolio — Developer Mode

Frontend HTML/CSS/JavaScript issu du ZIP, intégré à la branche feat/portfolio-game-ui.

Servir ce dossier avec un serveur HTTP statique (Live Server, par exemple), puis ouvrir index.html.
Aucune compilation ni installation npm nécessaire.

- data/projects.js : projets et statuts, y compris les deux projets à venir.
- data/data.js : contacts et parcours.
- data.js : fiches détaillées, captures et adaptation des données pour l'interface.
- app.js et style.css : navigation, mini-carte, téléphone DEV.OS, paramètres et galerie.
- Les URL demon-realm.html et asso-manager.html ouvrent leurs fiches respectives.

Les liens CV et LinkedIn restent à renseigner. Les informations de formation et de disponibilité sont conservées telles que fournies.
